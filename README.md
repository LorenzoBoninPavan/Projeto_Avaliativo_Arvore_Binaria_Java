# Projeto Bimestral: Implementação de Árvore Binária em Java

#Sobre o Projeto:
  Este projeto consiste no desenvolvimento de um sistema em Java para manipulação de uma Árvore Binária de Busca. O objetivo é aplicar conceitos fundamentais de algoritmos e estruturas de dados não lineares, oferecendo uma interface interativa via console.

#Funcionalidades do Sistema
1. Inserir um valor: Permite adicionar manualmente um novo elemento a árvore com um conjunto predefinido de valores de uma só vez.
2. Inserir valores automaticamente: Facilita testes rápidos ao popular a árvore com um conjunto predefinido de valores de uma só vez.
3. Buscar um valor: Realiza uma busca binária para verificar se um determinado elemento existe.
4. Remover um valor: Exclui um nó da árvore, tratando corretamente os casos de nós folhas, nós com um filho ou dois filhos
5. Varredura Em Ordem / E-R-D: Executa o percurso Esquerda-Raiz-Direita, exibindo os elementos da árvore em ordem crescente.
6. Varredura D-R-E: Executa uma varredura Direita-Raiz-Esquerda, exibindo os elementos em ordem descrescente.
7. Sair: Encerra a execução do programa.

#Tecnologias Utilizadas:
  Linguagem: Java;
# Conceitos aplicados:
  Estrutura de Dados(Nós, Ponteiros)
  Árvore Binária de Busca
  Algoritmo de Percurso
  Tratamento de menu interativo
